# Mansak Amin (مَنسَك آمن) 🕋✨

A digital platform and interactive web client designed to assist pilgrims during Hajj and Umrah, providing smart guidance and services to ensure a safe, smooth, and spiritually enriching journey.

---

## 🔗 Main Project Repository

> **📌 Important Note:**  
> This repository serves as the **hosted static frontend / live web client** deployed via GitHub Pages.  
> To view the complete project, core source code, and integrated backend services, please visit the main repository:  
> 👉 **[Main Project Repository](https://github.com/Hanan71/MansakAmin/tree/main/MansakAmin_modul-main)**.

---

## 🌟 Key Features
* **Intuitive & Responsive UI:** Fully mobile-friendly layout optimized for fast loading and seamless cross-device browsing.
* **Ritual Guidance & Safety Tips:** Clear, accessible instructions and information designed to keep pilgrims safe and informed.
* **Lightweight Deployment:** Instant serverless hosting directly powered by GitHub Pages.

---

## 🛠️ Tech Stack
* **HTML5:** Page structure and semantic layout.
* **CSS3:** Custom styling, animations, and responsive design.
* **JavaScript:** Dynamic interactions and client-side behavior.
* **GitHub Pages:** Static hosting and live continuous deployment.
