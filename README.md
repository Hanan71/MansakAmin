# Mansak Amin (مَنسَك آمن) 🕋✨

A digital platform and interactive web client designed to assist pilgrims during Hajj and Umrah, providing smart guidance and services to ensure a safe, smooth, and spiritually enriching journey.

---

## 🌟 Key Features
* **Intuitive & Responsive UI:** Fully mobile-friendly layout optimized for fast loading and seamless cross-device browsing.
* **Ritual Guidance & Safety Tips:** Clear, accessible instructions and information designed to keep pilgrims safe and informed.

## 🧠 Standalone AI Crowd Detection Module

This module runs locally **without launching the main website**.

* **Real-time Pilgrim Counter:** Detects and counts pilgrims in video streams.
* **Crowd Alert:** Automatically flags a **High Density / Congestion Alert** once the count reaches **60+ pilgrims**.
* **Quick Demo (`TryMe`):** Upload the included **`TryMe`** video to test real-time counting and trigger the overcrowding threshold.

### 🚀 Local Quickstart

```bash
cd MansakAmin_modul-main
pip install -r requirements.txt
python app.py  # or streamlit run app.py
```

1- Install required dependencies:
pip install -r requirements.txt

2- Run the local script / interface:
python app.py

# Or run via streamlit / main detection script:
# streamlit run app.py

Test the model:

Open the local interface on your browser (http://localhost:8501 or http://localhost:5000).

Upload the TryMe video file to view real-time pilgrim detection, count tracking, and overcrowding alerts.
